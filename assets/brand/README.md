# Diorama Journey identity

The first independent project Logo is a miniature cream gateway, sage island,
stone path and amber lantern, drawn from the original example world. The owner
approved the native 2048 × 2048 Sunburst image on 2026-09-17.

| Use | Asset |
| --- | --- |
| Canonical transparent foreground | `../../logo.png` |
| Large square presentation | `icon.png` |
| English and Chinese README header, 128 px | `icon-rounded.png` |
| Example viewer header, 24 CSS px | `../starter/public/brand/logo-48.png` |
| Example viewer browser tab | `../starter/public/brand/favicon.ico` |

Small marks use the transparent foreground without an extra background, shadow
or corner mask. The ICO contains transparent 16, 24, 32, 48, 64, 128 and 256 px
entries. README presentations include their own sage paper field and shallow
shadow. Resize the complete image uniformly; keep its original material colors.

The film's four-point star remains a story ornament in the reusable composition;
this Logo update does not rerender the example production. Scene materials,
viewer colors, fonts and narration are unchanged.

The source study is `hexly.ai/artwork/logo-family/diorama-journey/2026-09-17-01`,
finishing `01`. It preserves the exact prompt, image-model response, owner
approval, extraction, backgrounds, all ten export sizes and palette evidence.
See [identity.json](identity.json) for installed asset hashes and roles.
The [Hexly project archive](https://hexly.ai/projects/diorama-journey#brand)
provides the complete material package when published.

The Logo is generated raster artwork, not native SVG. Source image and reference
rights remain subject to the provider's terms and the owner's original project
rights; the repository's MIT license continues to cover Skill code and scripts.
